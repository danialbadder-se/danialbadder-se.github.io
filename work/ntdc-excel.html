How a description is built

The worksheet combines two voltage fields and the entered rating into one description. A second formula measures its length against the 20-character field in the master-data template. Choose a row to see the original inputs, formula, and result.

A detail worth checking

Row 2 ends in 250MVA. Row 3 contains 250MVH. Both descriptions are 16 characters long, so a length check passes both. I would verify the unit against the source record before changing it.
