The saved thresholds classify scores up to 44% as “real” and 66% or above as “fake”. Intermediate scores receive “uncertain”.

Model and testing

The Flask code combines two TF-IDF and Logistic Regression pipelines. One represents words and phrases, while the other represents character patterns. The app averages their predicted probabilities before applying the saved decision thresholds.

The checkpoint records 4,170 training examples and 1,390 held-out examples. Its thresholds were tuned using the holdout. The reported 88.42% accuracy describes this project evaluation.

I prepared functional and regression test cases for the web and extension workflows. Each defect report records the reproduction steps, expected behavior, actual behavior, and severity.
