# Muhammad Danial’s portfolio

Professional portfolio with original NTDC internship Excel samples, a Hospital Emergency Room dashboard, the VERITAS Python application, CAML-Net research results, and training credentials.

The website is served from the root of the main branch with GitHub Pages. Its public address is https://danialbadder-se.github.io/.

Edit the page content in `scripts/render_portfolio.py` and `scripts/internship_portfolio.py`, then run `python3 -B scripts/render_portfolio.py` to regenerate the homepage and project pages. Styles and interactive controls are in `styles.css` and `script.js`.

`data/` supplies the recorded project results and workbook samples. `documents/` contains the CV and the public project downloads.
